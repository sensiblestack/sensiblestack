# Sensible Stack (live site)

Static site for GitHub Pages. Plain HTML and one stylesheet, no build step beyond the generator that produced these files.

## Affiliate links
Every commercial link on the site points at a `/go/<tool>/` page in this repo, which redirects to the provider. To activate or change an affiliate link, edit only that tool's `go/<tool>/index.html` and replace the destination URL with the live affiliate URL. Articles never need editing.

## Pages
Home, About, How We Rate, Affiliate Disclosure, Privacy, Contact, three comparisons, two guides, and the Solopreneurs and Online Sellers segment pages. Remaining segment pages land month 2.
